# ZC0009 — File-Local Interface Is Not Generated

**Severity:** Error

The interface is declared `file`, or it is nested in a `file` type. A file-local type is visible only in the source file that declares it, so the generated proxy and `Add…Cache` extension method cannot refer to it. The generator reports ZC0009 on the interface and generates nothing for it. Other interfaces in the project are still generated.

---

## Example

```csharp
[Cache(TtlMs = 60_000)]
file interface IProductLookup               // ZC0009
{
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
}
```

---

## How to fix

Remove the `file` modifier, for example by making the interface `internal`:

```csharp
[Cache(TtlMs = 60_000)]
internal interface IProductLookup
{
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
}
```

To keep the interface file-local, remove `[Cache]` and write the caching decorator by hand.
