# ZC0003 — HybridCache Package Not Referenced

**Severity:** Error

At least one cached method on the interface uses `UseHybridCache = true`, but the project does not reference `Microsoft.Extensions.Caching.Hybrid`. The generated `Add{Service}Cache<TImpl>()` extension calls `services.AddHybridCache()`, which that package provides, so the generator cannot emit a working proxy. It reports ZC0003 on the interface and **generates nothing for that interface**: no proxy and no DI extension.

`UseHybridCache` counts whether it is set on the interface or on a method. The diagnostic is reported once per interface, however many methods use HybridCache.

On `net9.0` and later, `ZeroAlloc.Cache` brings `Microsoft.Extensions.Caching.Hybrid` in for you. In practice ZC0003 appears on `net8.0`, including the `net8.0` leg of a multi-targeted project.

---

## Example

```xml
<PropertyGroup>
  <TargetFramework>net8.0</TargetFramework>
</PropertyGroup>
<ItemGroup>
  <PackageReference Include="ZeroAlloc.Cache" Version="..." />
</ItemGroup>
```

```csharp
// ZC0003: UseHybridCache = true requires Microsoft.Extensions.Caching.Hybrid
[Cache(TtlMs = 60_000, UseHybridCache = true)]
public interface IProductRepository
{
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
}
```

---

## How to fix

**Option A — Add the package reference** to keep HybridCache on `net8.0`:

```bash
dotnet add package Microsoft.Extensions.Caching.Hybrid
```

**Option B — Target `net9.0` or later**, where `ZeroAlloc.Cache` already references the package:

```xml
<TargetFramework>net10.0</TargetFramework>
```

**Option C — Remove `UseHybridCache = true`** if the in-process `IMemoryCache` is enough:

```csharp
[Cache(TtlMs = 60_000)]
public interface IProductRepository
{
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
}
```

---

## When to suppress

Never. ZC0003 is an error because the generator emits no proxy for the interface, so there is nothing to register. Suppressing it only moves the failure to the missing `Add{Service}Cache<TImpl>()` call.
