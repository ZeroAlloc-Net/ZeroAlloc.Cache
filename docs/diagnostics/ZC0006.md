# ZC0006 — Containing Type Is Not Partial

**Severity:** Warning

A `[Cache]` interface nested in another type gets its proxy generated inside that type. To do that, the generated file reopens every containing type as `partial`, so each containing type has to be declared `partial`. When one is not, the generator reports ZC0006 on the interface, naming the outermost containing type that is not partial, and generates nothing for it: no proxy and no `Add…Cache` extension method.

---

## Example

```csharp
public static class Catalog                 // ZC0006: Catalog is not partial
{
    [Cache(TtlMs = 60_000)]
    public interface IProductLookup
    {
        ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
    }
}
```

---

## How to fix

Declare every containing type `partial`:

```csharp
public static partial class Catalog
{
    [Cache(TtlMs = 60_000)]
    public interface IProductLookup
    {
        ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
    }
}
```

The generated extension method is then named after the containing types, `AddCatalog_ProductLookupCache`. See [Nested interfaces](../getting-started.md#nested-interfaces).

---

## When to suppress

When the interface is not meant to be cached, remove `[Cache]` instead. Suppressing the warning leaves the interface without a proxy.
