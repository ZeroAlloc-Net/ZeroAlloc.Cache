# ZC0004 — Mixed MaxEntries Values

**Severity:** Warning

Two or more bounded methods on the same interface set different `MaxEntries` values. A bounded method is one with `MaxEntries > 0` that does not use HybridCache. The generated proxy does not give each bounded method its own cache. All bounded methods on the interface share **one** size-limited cache, and the first bounded method's `MaxEntries`, in declaration order, sets its `SizeLimit`. Each entry counts as size 1, so the limit is a combined entry count across those methods. Every other bounded method's `MaxEntries` value is ignored.

`MaxEntries = 0`, the default, is not counted as a different value. Those methods use the shared `IMemoryCache` from DI and do not count against the size-limited cache's `SizeLimit`. HybridCache ignores `MaxEntries`, so a hybrid method's value is neither compared nor used as the limit. The diagnostic is reported once, on the interface. The message names the value that is actually used.

---

## Example

```csharp
// ZC0004: SizeLimit is 500 for both methods; MaxEntries = 10_000 is ignored
public interface IProductRepository
{
    [Cache(TtlMs = 60_000, MaxEntries = 500)]
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);

    [Cache(TtlMs = 60_000, MaxEntries = 10_000)]
    ValueTask<Product?> GetBySkuAsync(string sku, CancellationToken ct);
}
```

`GetByIdAsync` and `GetBySkuAsync` together hold at most 500 entries, not 500 and 10,000.

---

## How to fix

**Option A — Use one `MaxEntries` value** for the whole interface, sized for the combined number of entries:

```csharp
public interface IProductRepository
{
    [Cache(TtlMs = 60_000, MaxEntries = 10_000)]
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);

    [Cache(TtlMs = 60_000, MaxEntries = 10_000)]
    ValueTask<Product?> GetBySkuAsync(string sku, CancellationToken ct);
}
```

Or set it once on the interface:

```csharp
[Cache(TtlMs = 60_000, MaxEntries = 10_000)]
public interface IProductRepository
{
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
    ValueTask<Product?> GetBySkuAsync(string sku, CancellationToken ct);
}
```

**Option B — Split the interface** when the methods really need separate limits. Each interface gets its own proxy and its own isolated cache.

---

## When to suppress

Never. If one shared limit is what you want, set every `MaxEntries` on the interface to the value in effect. The behavior is the same and the warning goes away, and the code no longer suggests per-method limits that do not exist.
