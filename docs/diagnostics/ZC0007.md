# ZC0007 — Generic Interface Is Not Generated

**Severity:** Warning

The interface is generic, such as `IRepository<T>`, or it is nested in a generic type, such as `Module<T>.IProductLookup`. The generated `Add…Cache` extension method has to sit in a non-generic static class at namespace level, and it cannot name the interface's type parameters. The generator reports ZC0007 on the interface and generates nothing for it.

---

## Example

```csharp
[Cache(TtlMs = 60_000)]                    // ZC0007
public interface IRepository<T>
{
    ValueTask<T?> GetByIdAsync(int id, CancellationToken ct);
}
```

---

## How to fix

Declare a non-generic interface for each type argument you cache, and put `[Cache]` on it:

```csharp
[Cache(TtlMs = 60_000)]
public interface IProductRepository
{
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
}
```

For an interface nested in a generic type, move it out of that type.

---

## When to suppress

When the interface is not meant to be cached, remove `[Cache]` instead. Suppressing the warning leaves the interface without a proxy.
