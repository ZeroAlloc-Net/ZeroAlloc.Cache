# ZC0010 — Interface Name Differs Only in Case

**Severity:** Error

Each `[Cache]` interface gets a generated file named after its namespace, its containing types and its name, such as `App.IProductLookup.Cache.g.cs`. The compiler compares these file names ignoring case, so two interfaces whose names differ only in case, such as `App.IProductLookup` and `App.IProductlookup`, cannot both get a file. The interface declared first, by file path and then position, is generated. Every later one gets ZC0010 and is not generated.

Before ZC0010, such a pair made the generator fail with CS8785, and no interface in the project got a proxy.

---

## Example

```csharp
namespace App;

[Cache(TtlMs = 60_000)]
public interface IProductLookup { ValueTask<string> GetAsync(int id); }

[Cache(TtlMs = 60_000)]
public interface IProductlookup { ValueTask<string> GetAsync(int id); }   // ZC0010
```

---

## How to fix

Rename one of the interfaces, or move it to another namespace or containing type.
