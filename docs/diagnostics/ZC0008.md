# ZC0008 — Interface Is Not Accessible From Its Namespace

**Severity:** Warning

The interface is `private`, `protected` or `private protected`, or it is nested in a type that is. The generated `Add…Cache` extension method sits in a class at namespace level, where such an interface cannot be named. The generator reports ZC0008 on the interface and generates nothing for it.

A `protected internal` interface is accessible to the whole assembly and is generated, with an `internal` extension method.

---

## Example

```csharp
public partial class Catalog
{
    [Cache(TtlMs = 60_000)]                // ZC0008
    private interface IProductLookup
    {
        ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
    }
}
```

---

## How to fix

Make the interface, and every type that contains it, `internal` or `public`:

```csharp
public partial class Catalog
{
    [Cache(TtlMs = 60_000)]
    internal interface IProductLookup
    {
        ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
    }
}
```

---

## When to suppress

When the interface is not meant to be cached, remove `[Cache]` instead. Suppressing the warning leaves the interface without a proxy.
