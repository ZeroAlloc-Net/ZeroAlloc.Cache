# ZC0011 — HybridCache Value Type Needs an AOT-Safe Serializer

**Severity:** Warning

A method with `UseHybridCache = true` caches a value type other than `string` or `byte[]`, in a project published with NativeAOT or trimming, and the compilation has no serializer for that type.

`HybridCache` serializes every value it stores, also when no distributed cache is configured. It handles `string` and `byte[]` itself. Every other type goes to its default serializer, which uses reflection-based `System.Text.Json`. Under NativeAOT that serializer throws on the first cache miss:

```
System.InvalidOperationException: Reflection-based serialization has been disabled for this application.
```

So the method works under the JIT and fails as soon as it is published with NativeAOT. ZC0011 reports this at build time. The fix is an `IHybridCacheSerializer<T>` that uses source-generated `System.Text.Json` metadata, registered with `HybridCache`.

ZC0011 is reported only when one of these MSBuild properties is `true`: `PublishAot`, `IsAotCompatible` or `PublishTrimmed`. The `ZeroAlloc.Cache` package makes them visible to the generator. It points at the method's own `[Cache]` attribute, or at the method when `UseHybridCache` comes from the interface's `[Cache]`.

Upstream, `Microsoft.Extensions.Caching.Hybrid` is not trim or AOT compatible itself, [dotnet/extensions#5624](https://github.com/dotnet/extensions/issues/5624). Publishing an app that uses `HybridCache` therefore also shows the package's own trim warnings, IL2104, IL3053 and IL2026, whatever the value type. A serializer fixes the run-time failure; those warnings remain until the upstream issue is fixed.

---

## Example

```xml
<PropertyGroup>
  <PublishAot>true</PublishAot>
</PropertyGroup>
```

```csharp
public sealed record Product(int Id, string Name);

public interface IProductRepository
{
    // ZC0011: caches 'Product' in HybridCache, whose default serializer uses
    // reflection-based System.Text.Json and throws under NativeAOT and trimming
    [Cache(TtlMs = 60_000, UseHybridCache = true)]
    ValueTask<Product?> GetByIdAsync(int id, CancellationToken ct);
}
```

---

## How to fix

**Option A — Register a serializer for the type**, backed by a source-generated `JsonTypeInfo`:

```csharp
using System.Buffers;
using System.Text.Json;
using System.Text.Json.Serialization;
using Microsoft.Extensions.Caching.Hybrid;

[JsonSerializable(typeof(Product))]
internal sealed partial class AppJsonContext : JsonSerializerContext;

public sealed class ProductSerializer : IHybridCacheSerializer<Product>
{
    public Product Deserialize(ReadOnlySequence<byte> source)
    {
        var reader = new Utf8JsonReader(source);
        return JsonSerializer.Deserialize(ref reader, AppJsonContext.Default.Product)!;
    }

    public void Serialize(Product value, IBufferWriter<byte> target)
    {
        using var writer = new Utf8JsonWriter(target);
        JsonSerializer.Serialize(writer, value, AppJsonContext.Default.Product);
    }
}
```

```csharp
builder.Services.AddHybridCache().AddSerializer<Product, ProductSerializer>();
builder.Services.AddProductRepositoryCache<ProductRepository>();
```

The serializer must be for exactly the cached type. A nullable reference annotation does not matter: `ValueTask<Product?>` needs an `IHybridCacheSerializer<Product>`. `Nullable<T>` does: `ValueTask<int?>` needs an `IHybridCacheSerializer<int?>`, not one for `int`.

For several types, write the serializer once as a generic class that takes a `JsonTypeInfo<T>`, and derive one sealed class per type:

```csharp
using System.Text.Json.Serialization.Metadata;

public class JsonTypeInfoSerializer<T>(JsonTypeInfo<T> typeInfo) : IHybridCacheSerializer<T>
{
    public T Deserialize(ReadOnlySequence<byte> source)
    {
        var reader = new Utf8JsonReader(source);
        return JsonSerializer.Deserialize(ref reader, typeInfo)!;
    }

    public void Serialize(T value, IBufferWriter<byte> target)
    {
        using var writer = new Utf8JsonWriter(target);
        JsonSerializer.Serialize(writer, value, typeInfo);
    }
}

public sealed class ProductSerializer() : JsonTypeInfoSerializer<Product>(AppJsonContext.Default.Product);
```

The open generic class alone does not satisfy ZC0011, because it does not say which types are registered; each derived class does.

**Option B — Register a serializer factory** that serves every type in your `JsonSerializerContext`, here with the `JsonTypeInfoSerializer<T>` above:

```csharp
using System.Diagnostics.CodeAnalysis;
using System.Text.Json.Serialization.Metadata;
using Microsoft.Extensions.Caching.Hybrid;

public sealed class AppJsonSerializerFactory : IHybridCacheSerializerFactory
{
    public bool TryCreateSerializer<T>([NotNullWhen(true)] out IHybridCacheSerializer<T>? serializer)
    {
        if (AppJsonContext.Default.GetTypeInfo(typeof(T)) is JsonTypeInfo<T> info)
        {
            serializer = new JsonTypeInfoSerializer<T>(info);
            return true;
        }

        serializer = null;
        return false;
    }
}
```

```csharp
builder.Services.AddHybridCache().AddSerializerFactory<AppJsonSerializerFactory>();
```

The generator cannot see which types a factory serves, so **any** `IHybridCacheSerializerFactory` in the compilation is trusted to cover every type and turns ZC0011 off for the whole project. Add each cached type to the `JsonSerializerContext`; a type the factory declines falls through to the reflection-based default and throws under NativeAOT.

**Option C — Return `string` or `byte[]`**, which `HybridCache` serializes without reflection, or drop `UseHybridCache = true` if the in-process `IMemoryCache` is enough.

---

## Where the serializer may live

ZC0011 looks for a concrete class or struct that implements `IHybridCacheSerializer<T>` or `IHybridCacheSerializerFactory`:

- anywhere in the project itself, or
- as a public type in a referenced project or package.

It checks that the serializer exists, not that it is registered. Register it as shown above; without the registration `HybridCache` still uses its reflection-based default.

A library that is `IsAotCompatible` and declares a `UseHybridCache` interface gets ZC0011 too. Ship the serializer with the library, next to the value type, so every app that uses the interface can register it.

---

## When to suppress

Not when the project is published with NativeAOT: the method throws on its first cache miss. Register a serializer instead.
